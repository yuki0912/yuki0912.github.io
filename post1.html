我的第一篇部落格文章：網頁設計起步走

歡迎來到我的網路小角落！這是我人生中第一次動手寫 HTML 和 CSS 來架設網站。雖然現在有許多現成的平台（如 Medium 或 WordPress），但能夠從零開始，親手敲出每一行程式碼，看著畫面呈現出自己想要的樣子，那種成就感是無可比擬的。

為什麼我想寫部落格？

在這個資訊爆炸的時代，我們每天都在接收海量的訊息，卻很少花時間好好內化。對我來說，寫作是一種梳理思緒的過程。透過文字記錄下自己學到的新技術或是生活感悟，不僅能幫助未來的自己複習，或許也能偶然啟發到網路上某個角落的讀者。

「最好的學習方式，就是把學到的東西教會別人。」—— 這是我一直很喜歡的一句話，也是這個部落格核心的宗旨。

接下來的計畫

未來我預計在這個空間分享兩個大方向：一是網頁前端技術的學習筆記，二是我平常生活中的閱讀心得與日常瑣事。如果你對這些主題感興趣，歡迎隨時回來逛逛！
